## 2026-11-22: whole call and kernel on the SH-2 model

- **What:** the lane times the kernel of MVMVA apart from the whole call. The gte and list bridges have the wrapper `sh2o_model_<fam>_mac3`: one out-of-line call of `sh2o_k_mvb3` (`_w2` native, C portable). With `SR.S` = 0, over the inputs on the kernel path (opcode `12h`, sf 1, mx < 3, cv != 2, each T word in the range of `sh2oi_mac3`), the harness times one `sh2o_gte_mvmva` call (whole) and one wrapper call (kernel) on the same matrix words, V and T. Before a figure is given, the whole call must give the oracle's 64 registers (list: the out row), each kernel `out[i]` must equal `(int64)T[i] << 12 + M[i].V`, and `(int32)(out[i] >> 12)` must equal the oracle's MAC1-3. 0 differences. A copy of each harness with one expected bit changed stopped with exit 1.

Portable: gte whole 475.58, kernel 210.00, overhead 265.58 (55.8%); list whole 472.08, kernel 210.00, overhead 262.08 (55.5%). This value uses emulator figures, and this lane's overhead is MODELLED. Thus the comparison of 266 with the overhead above is a screen, not the bar.
