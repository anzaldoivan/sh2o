# Validation record: 2026-11-21 (host and SH-2 model, psyq-setfarcolor-1)

Function `sh2o_psyq_SetFarColor` in `sh2o/psyq.h`, the contract of the PSY-Q libgte function `SetFarColor`: it writes the far colour to `CTC2` registers 53 to 55. The other records are listed in [VALIDATION.md](../VALIDATION.md).

- **Pins:** SH2ZAM `7f99eb70`, Yabause `7e38821d`, sh2eb-elf-gcc 13.2.0 in the pinned Yaul image (`ijacquez/yaul@sha256:b6d27220…`). Host compilers: GCC 16.2.1 and Clang 23.1.6.
- **Host, exact:** `make test` passes with GCC and with Clang. The psyq family has no oracle file. The test `psyq` runs the suite `tests/suite/sh2o_psyq_test_suite.c`: 1,216 cases (64 for each of the 19 bodies) give the digest `0xE430E70B`, which is its pin. Of these cases, 64 are SetFarColor cases. The mutant `far_colour_shift` changes SetFarColor. With it, the suite returns `0x500` (the digest is not the pin). The test `psyq_mutant_far_colour_shift` passes.
- **Game code, private:** the tests with the label `private` need the three variables `SH2O_PS1_LIBGTE_OBJECTS`, `SH2O_PS1_LINK_MAP` and `SH2O_PS1_DATA`. `ctest --test-dir build/gcc -L private` passes with the three variables set. The identity digest of the inputs is the pin. The test `psyq_identity` finds that the object bytes of SetFarColor have the sha256 of the header. The test `psyq_bodies` runs the object of SetFarColor in an R3000 interpreter (`scripts/psyq_model.py`) and the sh2o function on the same cases: 265 cases, 265 compared, 0 differences. With the mutant `far_colour_shift`, 263 of the 265 cases of `psyq_bodies` differ. When a variable is not set, each of these tests stops with exit code 77 (skipped).
- **SH-2 cross build:** `make cross`. `tests/sh2/psyq_static.txt` (`src/sh2o_psyq.c`, at `-Os` and `-O2`): the only undefined symbols are `sh2o_gte_read`, `sh2o_gte_write`, `sh2o_gte_command` and `__sdivsi3`; 20 globals `sh2o_psyq_`; no `MAC.W`; no `SETS`, no SR write, no divide step, no constant in the SH-2 divider area.
