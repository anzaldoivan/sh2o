# Validation record: 2026-11-22 (host and SH-2 model, gte-mvmva-list-prepared-1)

Function `sh2o_gte_mvmva_list_prepared` in `sh2o/gte_prepared.h`, source `src/sh2o_list_prepared.c`, with the inline kernels of [gte-mvmva-prepared-1](gte-mvmva-prepared-1.md) (`sh2oi_gte_prepared_mac3_l` on the SH-2, `sh2oi_gte_prepared_mac3_c` elsewhere). A second MVMVA list beside `sh2o_gte_mvmva_list` (record [gte-mvmva-list-1](gte-mvmva-list-1.md)), with the same arguments and the same contract. No default path calls it, and `sh2o/sh2o.h` does not include its header. [GTE.md](../GTE.md#mvmva-list-with-a-prepared-shadow) describes it. [VALIDATION.md](../VALIDATION.md) lists the other records.

## Why this kernel

- **Source of the method.** SH2ZAM at `7f99eb70`, not linked. From SH2ZAM: one prepared plan used for all the points of a range (guide `saturn/BATCH_TRANSFORMS.md:48-58`). Also the `MAC.L` batch candidate (guide `saturn/benchmarks/FUSED_SH2.md:1-7`, and kernel `saturn/src/sh2zam_batch_sh2.c:106`, three `MAC.L` rows for each point). Also one read of `SR.S` for each batch (kernel `saturn/src/sh2zam_batch_sh2.c:132`). The row kernel and the load are those of [gte-mvmva-prepared-1](gte-mvmva-prepared-1.md). The port also uses an earlier prototype of the same list (MIT), measured on an emulator.
- **Alternatives.** Today's list `sh2o_gte_mvmva_list`, one `sh2o_gte_mvmva` for each item (kept: the baseline and the fallback). The prototype's list, which used a shadow loaded before the call (adapted). This list loads its own shadow on the stack, one time for each call, only the matrix and the translation that `cmd` selects. So it keeps today's contract and can never use a stale shadow. The cost is one load for each list. A list that takes the caller's shadow (rejected for this tag: it changes the contract). A caller that keeps a shadow can call `sh2o_gte_mvmva_prepared` for each item. SH2ZAM's batch kernel (rejected: SH2ZAM source in sh2o, and Q16.16 with no GTE tail).
- **Inputs of the choice.** SH2ZAM: many points for each plan. The prototype: lists of 8 items, shadow loaded outside the timed call. Its emulator figure: 162.3 cycles an item. The consumer's measured workload: lists are 21.2% of its MVMVA calls, with a mean of 8.61 items. All of them use one command (`4A486012h`: sf 1, rotation matrix, V0, no translation). No consumer call of this list exists yet. This lane gives MODELLED figures.
- **The bar.** Exact on the host and on the lane at `SR.S` 0 and 1. Also, at n = 8 (the prototype's length, near the consumer's mean), fewer MODELLED cycles an item than today's list, the load included.
