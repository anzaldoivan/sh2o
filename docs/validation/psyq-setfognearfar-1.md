# Validation record: 2026-11-21 (host and SH-2 model, psyq-setfognearfar-1)

Function `sh2o_psyq_SetFogNearFar` in `sh2o/psyq.h`, the contract of the PSY-Q libgte function `SetFogNearFar`: it writes the depth cue registers DQA and DQB. [VALIDATION.md](../VALIDATION.md) lists the other records.

- **Pins:** SH2ZAM `7f99eb70`, Yabause `7e38821d`, sh2eb-elf-gcc 13.2.0 in the pinned Yaul image (`ijacquez/yaul@sha256:b6d27220…`). Host compilers: GCC 16.2.1 and Clang 23.1.6.
- **Host, exact:** `make test` passes with GCC and with Clang. The psyq family has no oracle file. The test `psyq` runs the suite `tests/suite/sh2o_psyq_test_suite.c`: 1,216 cases (64 for each of the 19 bodies) give the digest `0xE430E70B`, which is its pin. Of these cases, 64 are SetFogNearFar cases. The mutant `fog_no_break_hook` changes SetFogNearFar. With it, the suite returns `0x402`. Known answer 1 of `ratan2` (a divide by zero) fails, because the mutant removes the hook call of the divide that `SetFogNearFar` and `ratan2` share. The digest is the pin. The test `psyq_mutant_fog_no_break_hook` passes.
- **Game code, private:** the tests with the label `private` need the three variables `SH2O_PS1_LIBGTE_OBJECTS`, `SH2O_PS1_LINK_MAP` and `SH2O_PS1_DATA`. `ctest --test-dir build/gcc -L private` passes with the three variables set. The identity digest of the inputs is the pin. The test `psyq_identity` finds that the object bytes of SetFogNearFar have the sha256 of the header. The test `psyq_bodies` runs the object of SetFogNearFar in an R3000 interpreter (`scripts/psyq_model.py`) and runs the sh2o function on the same cases. It compares 1,212 of the 1,212 cases and finds 0 differences. In 109 cases the object stops at a `break` and sh2o calls the break hook. The test compares these cases. With the mutant `fog_no_break_hook`, 109 of the 1,212 cases of `psyq_bodies` differ. When a variable is not set, each of these tests stops with exit code 77 (skipped).
