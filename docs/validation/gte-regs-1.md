# Validation record: 2026-11-21 (host and SH-2 model, gte-regs-1)

Functions `sh2o_gte_read` and `sh2o_gte_write` in `sh2o/gte.h` (the register file, `src/sh2o_gte_regs.c`). [VALIDATION.md](../VALIDATION.md) lists the other records.

- **Pins:** SH2ZAM `7f99eb70`, Yabause `7e38821d`, sh2eb-elf-gcc 13.2.0 in the pinned Yaul image (`ijacquez/yaul@sha256:b6d27220…`). Host compilers: GCC 16.2.1 and Clang 23.1.6.
- **Host, exact:** `make test` passes with GCC and with Clang. The test `gte` runs the 30 `write` vectors of `tests/gte_oracle.h` with zero differences. That file has 177 vectors for all GTE functions. Each vector writes 61 registers in `sh2o_gte_order` on a zeroed image, then one more register. Two of them write a register above 63, which has no effect. Then each vector reads the 64 registers and the written register. The 147 `cmd` vectors and the 3,840 suite cases also go through `sh2o_gte_write` and `sh2o_gte_read`. The suite gives the digest `0xA50D51B1`, which is its pin. No gte mutant changes a result of the 30 `write` vectors (each mutant program, `--driver`, against the test program on these vectors).
- **Host, other sources:** the test `gte_sources` runs 72,397 cases of all the commands through `tests/test_gte.c --driver` and the Python model. The sources of the cases: edges 13,553, LCG 57,344, ps1-tests 1,500. The result: 0 differences on all 64 registers, FLAG included. The output shows the total only, not a count for each command. The test `gte_recordings` (private recordings, 75,261 cases) gave 0 differences in the record "GTE against the model" of [VALIDATION.md](../VALIDATION.md). It did not run again for this record.
- **SH-2 cross build:** `make cross`. `tests/sh2/gte_regs_static.txt` (native, at `-Os` and `-O2`): no undefined symbol. The same spec: no `SETS`, no GBR, no SR write, no divide step, no constant in the SH-2 divider area. The disassembly of these builds has no `MAC.W`. `tests/sh2/gte_suite_static.txt`: the suite object needs only `sh2o_gte_read`, `sh2o_gte_write` and `sh2o_gte_command`.
- **SH-2 model, exact:** `make sh2-model`. In the native and the portable program, the 30 `write` vectors have zero differences, with SR.S = 0. In each program, 177 of 177 vectors are exact. Each program gives the pinned digest `0xA50D51B1` over the 3,840 suite cases. Program sha256: native `d44e4d29…`, portable `9e32dfd4…`.
- **SR.S:** not affected. The register file has no `MAC.W`. The harness runs only the `cmd` vectors and the suite cases with SR.S = 1. Their totals (493 of 3,840 suite cases, 5 of 147 `cmd` vectors) are for the commands.
