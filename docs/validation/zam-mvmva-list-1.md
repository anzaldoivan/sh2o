# Validation record: 2026-11-21 (host and SH-2 model, zam-mvmva-list-1)

Function `sh2o_zam_mvmva_list` in `sh2o/zam_experimental.h`: the contract of `sh2o_gte_mvmva_list` (record [gte-mvmva-list-1](gte-mvmva-list-1.md)) through one prepared plan of SH2ZAM over the n points. Its domain is MVMVA with sf 1, mx < 3, V0, cv != 2, n of 32 or less, and the row gate of [zam-mac3-1](zam-mac3-1.md). Inside its domain it returns 1. Outside it, it writes nothing and returns 0. [ZAM.md](../ZAM.md) describes the delegate. [VALIDATION.md](../VALIDATION.md) lists the other records.

- **Pins:** SH2ZAM `7f99eb70`, Yabause `7e38821d`, sh2eb-elf-gcc 13.2.0 in the pinned Yaul image (`ijacquez/yaul@sha256:b6d27220…`). Host compilers: GCC 16.2.1 and Clang 23.1.6.
- **Host, exact:** `make test SH2O_ZAM=ON` passes with GCC and with Clang. The test `zam` compares the candidate with `sh2o_gte_mvmva_list` on the 64 registers and the out rows.
